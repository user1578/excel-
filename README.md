# Excel资料整理助手

## 项目简介

Excel资料整理助手是一个 Windows 本地桌面工具，用于维护学生基础资料、导入 Excel/CSV 资料、标准化考勤记录，并完成查询、汇总与 Excel 导出。

学生相关数据以**姓名、学号、班级**为核心字段，用于匹配、追溯和统计。

## 主要功能

- 学生、班级、班级别名和寝室基础库维护
- `.xlsx`、`.csv` 文件导入，支持 Sheet 选择、表头识别和字段映射
- 姓名、学号、班级匹配与班级别名标准化
- 异常数据待确认、文件重复检测和记录重复检测
- 考勤记录正式导入、导入历史和来源追溯
- 个人汇总、班级汇总、学生明细和 Excel 统计结果导出
- 手动创建和管理 Excel 模板
- 使用 DeepSeek 根据自然语言生成本地校验后的模板 Schema
- 多文件“资料汇总”：直接纵向合并或按学生安全关联
- “表格填充”：将汇总结果、单独的 Excel/CSV 或学生库资料另存填入既有 `.xlsx` 或 `.xls` 模板
- 新建模板和班级名单支持统一样式：标准办公表格、商务蓝色、极简表格及可配置样式

## 技术栈

- Python 3.11（建议）
- PySide6
- SQLite
- pandas
- openpyxl
- DeepSeek API（可选）

建议使用 Python 3.11。在项目根目录执行：

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## Windows 一键启动

普通使用时，双击项目根目录的 `启动Excel资料整理助手.bat` 即可启动。

首次运行如果缺少依赖，可按窗口中的中文提示选择自动安装。开发者仍然可以使用：

```bash
python main.py
```

## 基础使用流程

1. 在“学生库”“班级库”“寝室库”维护基础资料。
2. 创建整理任务后，在“资料导入”选择 Excel 或 CSV 文件、Sheet、表头和字段映射。
3. 检查学生匹配与“待确认”记录，再执行正式导入。
4. 在“汇总统计”按任务、日期、班级、学生、考勤类型和状态查询；可查看学生明细并导出 `.xlsx`。
5. 在“资料汇总”添加多个资料文件，逐个选择 Sheet 与表头行，分析后选择合并模式、处理冲突并导出。
6. 在“表格填充”选择现有 `.xlsx` 或 `.xls` 模板、目标 Sheet 与表头行，选择资料源和字段映射，预览后另存填写结果。
7. 在“模板生成”手动建立模板并设置样式，或填写自然语言需求后由 DeepSeek 生成 Schema，确认预览后再生成 Excel 模板。

## 资料汇总

“资料汇总”会先将每个来源表分析为内存中的 `TableDataset`，保留列、行、来源文件、来源 Sheet、原始行号和自定义字段，再进行合并；不会把未知列降级后丢弃。

### 直接纵向合并

各来源行会纵向追加，输出字段为所有来源字段的并集。列顺序不同不会造成错位，来源缺少的字段保持为空。来源追溯信息保留在内存结果与冲突记录中。

### 按学生关联合并

关联优先级严格为：

1. 相同且非空的学号。
2. 姓名加规范化班级。
3. 仅在全量输入没有矛盾身份线索、候选唯一时的姓名。
4. 其他情况不自动合并。

相同非空学号可在学生库尚未存在该学生时关联。重名学生不会因为名称相同而自动关联；姓名相同但班级不同会保持为独立记录。

### 冲突处理与导出

同一关联记录的同一字段出现不同非空值时，系统创建 `MergeConflict`，记录两侧值、文件、Sheet、行号和解决状态。默认保留 A 值但**不等同于解决冲突**，不会执行 last-write-wins 覆盖。可选择使用 A、使用 B、手动输入或暂不解决。

存在未解决冲突时，导出前必须由用户在界面中再次明确确认；导出文件包含“汇总结果”“汇总说明”，有冲突时还会包含“字段冲突”工作表。输出文件保存到 `exports/`，不会覆盖已有文件。

## 表格填充

表格填充支持 `.xlsx` 模板和 `.xls` 旧版模板。选择 `.xls` 时，程序仅通过本机 Microsoft Excel 以只读方式生成临时 `.xlsx` 工作副本；原文件不会被保存或改写，填写结果始终为新的 `.xlsx`。若缺少 pywin32，会提示安装该 Python 条件依赖或先用 Excel/WPS 另存为 `.xlsx`；若 pywin32 已有但无法启动 Excel 自动化服务，也会给出单独提示。`.xlsm` 不支持。数据源可为当前资料汇总结果、单独选择的 `.xlsx/.csv` 文件或学生库。系统会根据标准字段、字段别名与手工映射匹配模板字段，例如“姓名→学生姓名”“学号→学籍号”。

模板只会被读取，结果总是另存到 `exports/`，原模板不会被原地修改。填充时会保留工作表既有列宽、冻结窗格、打印设置、合并区域与已有公式；新增行以首个模板数据行为样板，并使用 `openpyxl.formula.translate.Translator` 平移相对或混合引用公式，不使用字符串替换行号。

若映射目标位于 merged cell 的非左上角，系统会明确拒绝写入，不会拆分或破坏合并区域。模板目标单元格已有值时，可选择：保留原值、使用新值，或跳过整行。预览会显示已有值冲突和合并单元格风险。

模板含明确的“序号”“序”或“编号”表头时，默认提供“自动序号”映射；也可以把任意目标列手工映射为自动序号。可设置起始值，并选择仅补空白、重新连续编号或不处理。自动序号是填写输出规则，不会添加到来源数据集；使用“跳过有冲突的行”时，成功写入的记录仍保持连续编号。

## 模板样式与大标题

“标准办公表格”是默认预设：白底黑字、黑色完整细边框、表头加粗居中换行、正文居中、正常灰色网格线且默认不显示筛选箭头。常见字段会给出保守列宽建议；字段单独列宽优先。商务蓝色、极简和自定义样式仍可选择。

样式对话框提供大标题模式：生成时询问、不使用、使用模板名称或自定义。选择“生成时询问”时，仅在真正生成模板的一次操作中决定是否添加合并大标题；有标题时第 2 行为表头，无标题时第 1 行为表头。班级快速生成同样可选择不使用、默认或自定义标题。

冻结窗格可选择“不冻结”“冻结表头”或“生成时询问”。标准办公表格默认不冻结，商务蓝色默认冻结表头；若选择生成时询问，生成时的选择仅作用于本次文件，不会改写样式设置。冻结时，无标题模板从 `A2` 开始冻结，有标题模板从 `A3` 开始冻结。

新建模板和班级名单默认按内容自动调整列宽、表头和数据行高：字段手工列宽最高优先，常见字段使用语义建议，中文与全角字符按较宽显示估算，过长内容保持换行并限制最大宽度。关闭“根据内容自动调整”后使用原有固定行高和列宽规则。已有 Excel 模板的“表格填充”始终保留原列宽、行高和冻结窗格，不应用这些新样式规则。

## 日期与 Excel 安全策略

导入日期会尽量规范为 `YYYY-MM-DD`，支持 Python/Pandas 日期对象、Excel 日期序列号、`YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY.M.D`、中文年月日和常见带时间格式。模糊或不可可靠解析的内容会保留原文本，不会猜测错误日期。

所有写入 Excel 的用户来源文本，如以 `=`、`+`、`-`、`@`、Tab 或回车开头，会前置单引号，防止 Excel 公式注入。程序生成且受控的公式不经过这一步，仍作为公式写入。

## DeepSeek 配置

在程序“设置”页面配置是否启用、API Key、模型名称和 API 地址，并可使用“测试连接”验证配置。

真实 API Key 仅保存在本机 `.env`，不会上传 GitHub；请勿在代码、日志或文档中填写真实 Key。

## 支持格式

- `.xlsx`
- `.xls`（仅作为表格填充模板输入；需本机 Microsoft Excel，转换后输出 `.xlsx`）
- `.csv`
- `.txt`（表格填充的数据源；依次尝试 UTF-8、UTF-8 BOM、GB18030）

`.xlsm` 不支持；数据源 `.xls` 暂不支持，旧格式支持范围仅为模板输入。

## V2.1：基础资料、文本填充与班级名单

### 用三个班级学生信息表初始化基础库

先在“资料汇总”添加三个虚构或实际班级表，逐一确认 Sheet 与表头，执行“直接纵向合并”后检查结果。点击“导入基础库”会先给出新增/已有/冲突的班级、寝室与学生预览；只有确认后才写入本机 SQLite，并在同一事务内按“班级 → 寝室 → 学生”顺序执行。失败时整次导入会回滚。

资料汇总适合收集来源表、保留未知列和处理跨文件冲突；它不等同于一份完整学生档案。基础库导入会将固定核心资料与可扩展资料分开保存，避免将未来字段塞进备注。

### 班级、寝室与学生规则

- 班级从 `class_name` 去重提取；空名称不会创建。已有班级不会重复创建，专业或年级的非空不一致会在预览中标为冲突，绝不静默覆盖。
- 寝室优先读取标准寝室、楼栋与房间号；也会保守识别 `7栋-302`、`7栋302`、`7-302`。无法可靠拆分的寝室会列为待确认，绝不会猜测楼栋或房间号。
- 学号是学生唯一身份。相同姓名但不同学号始终是不同学生；相同学号但姓名或班级不一致会标为冲突，不自动更新。
- 已有学生默认只补全空字段。新旧均非空且不同（例如手机号）会列为冲突，不会覆盖原值。

### 学生扩展资料

学生库编辑窗口的“扩展资料”可新增、修改和删除字段，例如性别、民族、政治面貌、家庭住址或父母联系方式。它们保存到本机 `student_extra_fields`，以稳定的字段键去重；不会动态修改 `students` 表结构。导入资料汇总时，所有非核心列会保留为扩展资料。

### 粘贴文本与 TXT 填充

“表格填充”的数据源新增“粘贴文本”“TXT 文件”和“班级学生”。粘贴文本和 TXT 均先显示识别字段、行数和预览，确认后才进入既有的字段映射、预览、另存填写流程。

TSV 示例（从 Excel 复制时通常就是 Tab 分隔）：

```text
姓名	学号	班级	参赛
测试学生甲	20260001	测试班2401	是
测试学生乙	20260002	测试班2401	否
```

键值示例（支持中文冒号、英文冒号和 `=`；空行分隔记录）：

```text
姓名：测试学生甲
学号：20260001
班级：测试班2401
参赛：是

姓名:测试学生乙
学号=20260002
班级:测试班2401
参赛:否
```

无法由本地规则可靠解析的自然语言，可在已配置并启用 DeepSeek 后使用“AI 结构化解析”。程序只发送用户当前粘贴在输入框中的文本，不会发送本地学生库、扩展资料或任何后台数据库内容。AI 只能返回列/行 JSON，仍必须经过本地预览和用户确认，不能直接写数据库、修改 Excel 或保存文件。

### 查看班级学生与生成表格

班级库的“查看学生”可按姓名、学号、专业或寝室搜索，并可全选、取消全选或单独勾选。选择后可：

- “生成表格”：设置可选主标题、表格样式、列宽、添加/删除/上下移动列、修改显示标题，并使用自动序号、核心字段、扩展字段、空白字段或固定内容作为每列的数据来源。标题不为空时写在第一行并合并，字段表头位于第二行；否则第一行就是表头。
- “按模板生成”：将所选学生（含扩展资料）转换为 `TableDataset`，切换到“表格填充”，继续使用学校已有 `.xlsx` 或 `.xls` 模板、字段映射和安全另存。

快速生成的文件会另存到 `exports/`，采用安全文本转义、表头样式、合理列宽；冻结窗格和自动筛选由所选样式决定，不会覆盖已有文件。班级表方案可保存、加载与删除；方案只保存列配置和标题，不保存任何学生数据，且同名方案不会被静默覆盖。

## 当前限制

- `.xls` 只支持作为表格填充模板输入，依赖本机 Microsoft Excel；数据源 `.xls` 与 `.xlsm` 暂不支持。
- `.xlsm`、VBA 宏、PivotTable、Slicer、外部链接、第三方扩展和部分高级 Office 对象不在模板原样保存保证范围内。项目使用 openpyxl，不能承诺这些复杂对象 100% 无损。
- 暂不支持 OCR、PDF/Word 自动解析和查寝照片管理。
- AI 模板生成依赖网络连接和可用的 DeepSeek API 配置。
- 当前逐人考勤记录不用于直接计算应到、实到或到课率；准确计算这些指标需要后续的班级场次模型。

## 数据安全

用户原始文件不会被程序修改。正式数据库以及 `imports/`、`exports/`、`templates/`、`backups/` 和附件等运行数据默认不上传 GitHub；仓库仅保留必要的 `.gitkeep` 和测试 fixture。
